# Simulating the Wake and the Whisker

Project website: https://fbg-whisker-cfd.github.io/

Repository: `fbg-whisker-cfd/fbg-whisker-cfd.github.io`.

2D fishtail-wake and 3D whisker fluid–structure simulations by Xiaochi Xie and
Siyue Yao that guided the fishtail and whisker parameters of the FBG Whisker
experiments.

Static HTML, CSS, JavaScript and media. Published with GitHub Pages from the
`main` branch root; no build command is required.
